# Wi-Fi Security Verification Checklist

- [ ] Security mode is WPA3-Personal, or WPA2-Personal with AES/CCMP
- [ ] WEP, WPA and TKIP are not enabled
- [ ] Wi-Fi passphrase is long (16+), unique, and not shown in screenshots
- [ ] Default router administrator credentials changed
- [ ] Router admin page uses HTTPS (where available)
- [ ] WPS disabled (or justified)
- [ ] Remote management disabled (or restricted and justified)
- [ ] UPnP disabled unless required
- [ ] Guest network enabled with client isolation
- [ ] Protected management frames (802.11w) enabled
- [ ] Firmware is current, from the manufacturer's official source
- [ ] SSID does not reveal personal or router-model information
- [ ] Connected-device list reviewed; unknown devices investigated
- [ ] Authorised devices reconnect successfully after changes
- [ ] Settings reviewed again on a regular schedule (e.g. every 3 months)
